# Morphology and Spatial Localization

Use this reference when cells, tissues, organelles, anatomy, or injury microenvironments must be visually identifiable.

## Core rule

A key biological object must be recognizable by more than color alone. Use shape, texture, location, scale, and local context.

## Cell identity checks

For every required cell, verify:
- characteristic overall morphology
- plausible size relative to neighboring cells
- correct tissue or compartment location
- correct membrane/nuclear relationship when relevant
- no visual duplication that makes distinct cell types indistinguishable

Examples:
- resting macrophage: rounded to mildly irregular, compact, few short protrusions
- activated macrophage: more irregular/spread, membrane ruffling/pseudopodia
- T cell: small round lymphocyte with high nucleus-to-cytoplasm ratio
- fibroblast/FAP-like stromal cell: spindle/elongated in interstitial connective tissue
- endothelial cell: flattened/elongated lining a vessel
- satellite cell: small cell apposed to the myofiber, beneath/adjacent to basal lamina context rather than floating freely
- myoblast: mononuclear elongated progenitor progressing toward alignment/fusion

Do not infer functional phenotype solely from morphology when the biology requires molecular evidence. Use labels when needed.

## Organelle and structure checks

- nucleus: plausible intracellular position and scale
- mitochondria: intracellular, not extracellular decoration
- ER/Golgi/lysosome: use only if mechanistically relevant
- receptor: membrane-bound unless biology indicates otherwise
- secreted mediator: extracellular after release

## Anatomy and injury

Anatomical highlighting must match the real structure and orientation. For muscle injury/regeneration, distinguish:
- intact myofiber
- disrupted/necrotic myofiber
- hematoma or local bleeding when relevant
- inflammatory infiltrate
- interstitial ECM
- regenerating myotube/myofiber
- revascularization

## Spatial QA

Fail the figure if a scientifically essential object is recognizable only by a legend but is drawn in an implausible location or morphology.
