# Reference Decomposition

Use when the user supplies a reference figure and asks for a similar visual language.

## Extract visual grammar only

Record:
- layout and reading direction
- panel count and grouping
- camera angle / perspective
- 2D, 2.5D, 3D, or hybrid rendering
- object realism and material style
- lighting and shadow intensity
- background treatment
- saturation and dominant hue families
- typography density
- arrow and leader-line style
- whitespace and alignment
- primary and secondary visual anchors

## Extract scientific information architecture

Also inspect how the reference organizes scientific information:
- main scientific story
- primary mechanism region
- supporting modules
- macro→micro scale transitions
- organism→organ→tissue→cell→molecule nesting
- material→microstructure→cell response→tissue outcome chains
- zoom-in / callout frequency and source-destination logic
- balance between one dominant anchor and smaller supporting units
- how experimental validation is integrated with mechanism
- whether dense information is grouped into readable modules or merely crowded

Prefer borrowing this structural logic over copying decorative appearance.

## High-value patterns to recognize

- organism/animal context with highlighted local site and zoomed mechanism
- implant/material with microstructure inset plus tissue-interface response
- synthesis/preparation workflow feeding into mechanism and biological validation
- cell-level mechanism embedded inside a larger tissue or defect context
- final repaired/regenerated state positioned as a scientific endpoint rather than a promotional badge

## Do not transfer unsupported science

A reference image may guide:
- style
- composition
- hierarchy
- rendering
- annotation grammar
- scale-transition strategy
- callout structure
- information-density strategy

It must not automatically supply:
- entities not requested by the client
- mechanisms not supported by the source
- disease-specific claims
- numerical data
- anatomical details that conflict with the target topic
- extra cell types, markers, pathways, or materials added only to mimic visual complexity

## Reference role classification

Classify the reference as one or more of:
- style reference
- composition reference
- scientific-content reference
- color reference
- rendering reference
- information-architecture reference

If scientific-content reference is claimed, verify that the source actually supports the borrowed content.

## Reference-quality check

A visually impressive reference is not automatically a good scientific template. Extract only the parts that improve:
- scientific clarity
- hierarchy
- scale communication
- object specificity
- interpretability

Do not copy overcrowding, unreadably small labels, excessive panels, decorative gradients, or unsupported pseudo-data simply because they appear in the reference.
