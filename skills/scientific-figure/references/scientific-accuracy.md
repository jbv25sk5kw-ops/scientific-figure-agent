# Scientific Accuracy

## Evidence boundary

Classify each claim:

- E1 client-confirmed or directly supported by supplied source
- E2 stable structural/context knowledge
- E3 proposed or hypothesized mechanism
- E4 unsupported; do not include as confirmed

If a critical claim is not E1/E2, either verify it externally or visually mark uncertainty.

## Relationship semantics

- Confirmed causal relation: solid directional arrow
- Proposed/hypothesized relation: dashed arrow + concise label if needed
- Indirect association: dotted line/arrow
- Inhibition/blockade: T-shaped blunt line
- Unknown: neutral gray; do not imply certainty

## Mandatory checks

Check names, direction, cell source, tissue location, subcellular localization, temporal order, intervention target, and whether any pathway was invented.

For parallel downstream consequences, do not chain them unless literature supports a serial dependency.

## Schematic–data boundary

Never invent real-looking curves, bars, percentages, fold-changes, proportions, scale bars, or axes. If a trend is conceptual, use qualitative progression or label it explicitly as schematic.

## Scientific QA outcome

- PASS
- NEEDS_REVIEW
- FAIL

Critical scientific errors always override visual quality.
