# Layout Density and Canvas Occupancy

Use this reference when deciding how tightly scientific content should fill the canvas.

## Core principle

White background is acceptable; meaningless whitespace is not.

Do not assume that every publication-quality figure should be sparse. Some figures need high whitespace, while others—especially biomaterials, tissue engineering, nanomedicine, drug delivery, regenerative medicine, and complex multiscale biomedical figures—look more professional when the canvas is densely but deliberately organized.

The goal is not to eliminate whitespace. The goal is to eliminate unintentional empty space while preserving hierarchy and readability.

## Layout density router

Choose one mode before composing the figure.

### LD1 — Minimal / Clean
Use for highly simplified conceptual schematics, very focused mechanisms, or when the user explicitly requests a sparse style.

Characteristics:
- generous whitespace
- few modules
- one dominant anchor
- very low text density

### LD2 — Balanced
Default for standard manuscript/thesis mechanism figures.

Characteristics:
- moderate whitespace
- clear main mechanism
- several supporting modules
- balanced density without crowding

### LD3 — Dense Scientific Layout
Use when the task or reference style contains complex biomaterial, bioengineering, tissue-engineering, drug-delivery, multiscale, or multi-module biomedical content.

Characteristics:
- high information density
- low unused whitespace
- strong canvas utilization
- multiple meaningful scientific modules
- frequent but disciplined callouts/zoom-ins
- corners and edges used intentionally
- full but not chaotic

If a reference resembles dense biomaterials or multiscale biomedical figures, default to LD3 unless the client explicitly requests minimalism.

## Canvas occupancy rule

For LD3 figures, aim for roughly 75–90% of the useful canvas to contain meaningful scientific content.

This is a composition target, not a rigid measurement.

Prefer:
- scientific content in top, bottom, left, and right regions
- short transitions between modules
- compact use of margins
- integrated callouts rather than isolated floating objects

Avoid:
- large empty corners without purpose
- a narrow central strip surrounded by unused canvas
- a few oversized icons used only to fill space
- wide PowerPoint-like gaps between modules

## Four-corner fill principle

In LD3 mode, consider whether each corner can carry useful scientific information.

Typical roles:
- top-left: starting material, trigger, synthesis, disease onset
- top-right: microstructure, targeting/delivery, local callout, intermediate mechanism
- bottom-left: cell response, molecular pathway, experimental mechanism
- bottom-right: tissue outcome, animal validation, repair/regeneration, treatment result

Not every corner must be equally dense. An empty corner is acceptable only when it clearly supports hierarchy, readability, or a callout path.

## Edge-to-edge scientific composition

Dense figures should feel integrated rather than like isolated objects on a slide.

Prefer:
- continuous left-to-right or top-to-bottom scientific flow
- nested callouts
- linked modules
- compact stage transitions
- organism→organ→tissue→cell→molecule or material→microstructure→cell→tissue nesting

Use whitespace between modules as a separator, not as unused dead space.

## Module packing rule

If the figure feels sparse, do not simply enlarge a few icons.

Instead, identify scientifically meaningful supporting modules.

Typical supporting modules include:
- synthesis/preparation
- micro/nano structure
- targeting/delivery
- cellular uptake or response
- intracellular mechanism
- tissue microenvironment
- in vivo validation
- repair/regeneration or therapeutic outcome

For LD3, use one primary mechanism anchor plus 2–4 subordinate scientific modules when the evidence supports them.

Do not add unsupported biology just to fill the page.

## High-density biomedical figure style

Common characteristics:
- white or pale background
- multiscale scientific structure
- multiple compact modules
- several local magnifications
- specific scientific objects rather than generic icons
- mechanism and validation integrated in one visual system
- limited meaningless whitespace
- clear main story despite dense detail

This style is especially suitable for:
- biomaterials
- nanomedicine
- tissue engineering
- regenerative medicine
- wound healing
- orthopedics
- dental biomaterials
- immunoengineering
- drug delivery

## Whitespace audit

After generation, check:
- Is the composition unintentionally concentrated in the center?
- Are large regions of the canvas unused?
- Are two or more corners blank without compositional purpose?
- Are modules too far apart?
- Is the figure relying on oversized generic objects instead of useful supporting modules?
- Does the density match the selected LD mode?

Severity guidance:
- L1: minor excess whitespace
- L2: noticeable under-utilization of canvas
- L3: strong mismatch with an explicitly requested dense/full-canvas scientific style

## Final rule

A dense scientific figure should be:
- full, not messy
- information-rich, not overloaded
- layered, not scattered
- professional, not decorative
- full-canvas, not empty-slide-like

Fill space with science, not decoration.
